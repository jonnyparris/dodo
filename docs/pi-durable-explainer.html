Dodo now runs its agent loop on pi-durable

One page on what was swapped, why, and what is left. Phase 1 is live, opt-in per session (PUT /session/:id/engine {"engine":"pi"}). Existing sessions are untouched.

The change in one sentence

The code that runs a turn (call the model, run the tools it asks for, repeat) used to be Dodo's own loop on top of @cloudflare/think. It is now the Harness from @earendil-works/pi-durable, a maintained library that saves every step to the Durable Object's SQLite before it moves on.

What was swapped out

JobBefore (Dodo-owned)Now (pi-durable / pi-ai)
Run the turnOwn-loop in onChatMessage, one streamText per step (~700 lines)Harness generation task
Run a tool callInline in the loop, in memoryA durable task per call, saved before it runs, with a replay rule
Survive evictionFiber checkpoint after the whole chatSubmission keyed by prompt id; reattach and continue
Keep context smallmaybeCompactContext, compaction policy, in-memory pruning, overflow retryBuilt-in background + blocking compaction, overflow retry
Talk to the gatewayAI SDK provider + Dodo's Anthropic cache-marker rewrite + affinity headerpi-ai openai-completions with compat settings
Retries / abortAd hoc in the loopRetry with backoff; abort cascades into running tools

Unchanged: every tool (adapted, not rewritten), the system prompt, the prompt queue and lifecycle, goals, watchdog, attachments, and the SSE events the UI listens to.

What we get

  • Reliability: progress inside a turn survives restarts; side effects aren't replayed; storage errors fail loud instead of half-saving.
  • Performance: only changed system-prompt sections are re-sent, which keeps provider prompt caches warm. Live: turn 2 of a pi session sent 445 uncached input tokens against 20,218 for turn 1 (the rest came from the provider's cache). Fewer replays means fewer wasted tokens.
  • Less code to own: about 1,900 lines become deletable once pi is the default, plus the @cloudflare/think dependency.
  • Maintained upstream: fixes land in a shared library with its own test suite. We contribute back instead of patching locally.
  • Cost: the Worker bundle grows by 343 KiB gzipped (the OpenAI SDK inside pi-ai) until the Think path is deleted.

Also shipped, and what's next

  • Kitebuild ci_run tool: Dodo pushes a branch, and Kitebuild (BusyBox on Workers, no container) clones it and runs npm ci, npm test, tsc, and so on. It stays off until a Kitebuild Access service token is configured.
  • Upstream fix ready: pi-ai sent Authorization: Bearer unused next to AI Gateway's header, which caused a 401. The patch and test are on a local branch. pi requires the issue to be filed by a person, in their own words.
  • Before pi becomes the default: session fork/snapshot on pi history, context-usage numbers from pi.usage, and the doom-loop check ported as a pi hook. Then delete the Think path.
